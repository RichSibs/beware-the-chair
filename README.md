# Beware The Chair – website

Static site for the iOS game *Beware The Chair*, hosted on GitHub Pages. Holds the pages App Store Connect needs:

- `index.html` – marketing URL
- `support.html` – support URL
- `privacy.html` – privacy policy URL

Edit the HTML, commit, and Pages republishes in about a minute. Keep `privacy.html` in step with the App Privacy answers in App Store Connect.
